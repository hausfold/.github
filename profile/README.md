## the repos

- **[haus](https://github.com/hausfold/haus)** — the whole desktop, one Nix flake. **start here.**
- **[pounce](https://github.com/hausfold/pounce)** — a keyboard-first command palette.
- **[perch](https://github.com/hausfold/perch)** — a file shelf that grows out of the notch.
- **[trill](https://github.com/hausfold/trill)** — a quiet notification compositor.
- **[nebelung](https://github.com/hausfold/nebelung)** — the color theme underneath it.
- **[holt](https://github.com/hausfold/holt)** — the worktree substrate parallel coding agents use.
- **[workshop](https://github.com/hausfold/workshop)** — where the family gets built.
